# PionixPublic

Welcome to **Pionix Public GitHub Repository**.  
This organization is dedicated to open-source development of both hardware and software related to Pionix products.  
Here you’ll find evaluation boards, reference designs, firmware, and other tools — free for anyone to inspect, fork, or contribute to 🛠️

If you want to contribute, or need support, please feel free to open issues or pull requests in the respective repositories.

All projects here are designed to be compatible with the EVerest open source charging stack: https://github.com/EVerest
